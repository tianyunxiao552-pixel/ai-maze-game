# AI 迷宫追逐小游戏

一个使用 Python 和 Tkinter 编写的迷宫追逐游戏。玩家收集能量点、躲避敌人并到达出口；敌人通过 BFS（广度优先搜索）寻找最短路径，并采用不同的目标选择策略。

## 功能

- 方向键或 WASD 控制玩家移动。
- 收集能量点获得分数，收集 12 个后开启出口。
- 三种敌人策略：追踪当前位置、预测移动方向、在出口附近守卫。
- 提供相邻格子的避险提示。
- 支持生命值、计分、关卡升级、暂停和重新开始。
- 使用标准库，无需安装第三方 Python 包。

## 运行环境

- 建议使用 Python 3.9 或更新版本。
- Python 环境需要支持 Tkinter 图形界面。

先确认 Tkinter 可用：

```bash
python -m tkinter
```

如果弹出测试窗口，就可以运行游戏。若提示缺少 tkinter，需要为当前 Python 环境安装 Tk 支持。

## 启动游戏

下载仓库文件，在项目目录打开终端并运行：

```bash
python ai_maze_game.py
```

Windows 也可以使用：

```powershell
py ai_maze_game.py
```

## 操作说明

| 按键 | 功能 |
| --- | --- |
| 方向键 / 小写 WASD | 移动 |
| P | 暂停或继续 |
| R | 重新开始 |

蓝色圆形是玩家，黄色圆点是能量点，彩色方块是敌人。绿色出口在收集足够能量后开启，到达出口即可进入下一关。每个能量点得 10 分，通过一关额外得 100 分；初始生命值为 3。

## 算法与代码结构

这里的 AI 指基于图搜索和规则的游戏智能体。程序将可通行的格子视为图的节点，上下左右的可通行相邻格子构成边；BFS 在这些等权边上寻找最短路径。

敌人根据策略选择目标，然后沿 BFS 给出的路径移动一步：

- **追踪者**：以玩家当前位置为目标。
- **预测拦截者**：根据玩家移动方向选择前方的可通行目标格。
- **出口守卫**：玩家接近时追踪玩家，否则前往出口附近。

避险提示比较当前格子及其相邻格子与敌人的最短距离，选出距离最近敌人最远的候选格。这个提示是局部启发式建议，不能保证逃脱。

| 类 | 职责 |
| --- | --- |
| `Config` | 地图尺寸、生命值等参数 |
| `Maze` | 地图解析、邻居查询和能量点生成 |
| `SearchAI` | BFS 寻路、距离计算和避险提示 |
| `Player` / `Enemy` | 玩家状态和敌人决策 |
| `GameStats` | 运行统计 |
| `GameApp` | Tkinter 界面、输入和游戏循环 |
